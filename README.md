
# Hi, I'm Tomer Klein

👋 I'm a passionate C#/Python/Go developer with a knack for IoT innovations and a fervent love for open source projects. I thrive on turning smart home dreams into reality, weaving technology into everyday life.

🌟 My journey involves not just writing code but creating experiences. I believe in the transformative power of technology to improve our lives and I'm on a mission to make it happen.

## About me

* 🐳 I build and publish self-hosted apps as Docker containers — 90+ images on [Docker Hub](https://hub.docker.com/u/techblog)
* 🏠 I love to contribute to home automation projects: Home Assistant integrations, MQTT, ESP32 and Raspberry Pi
* 💬 I build WhatsApp and Telegram bots, notification bridges and n8n community nodes
* 📡 I write monitoring and network tools: Prometheus exporters, DNS and certificate monitors, Red Alert (Pikud HaOref) tooling
* 🤖 I love electronics and DIY projects 😁
* 📝 I blog at [techblog.co.il](https://techblog.co.il)
* 💬 Ask me about anything, I am happy to help 😄
* 🧗 I try to: Go beyond and push the bounds
* ⚡ Fun fact: I love connecting with different people 🙌
